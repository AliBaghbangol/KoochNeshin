# کوچ‌نشین — پلتفرم تور و تجهیزات گردشگری ایران

پلتفرم کامل تورگردی و فروشگاه تجهیزات کمپینگ با رابط فارسی (RTL)، شامل:

- **فروشگاه تورها** — جستجو، فیلتر، مقایسه، جزئیات کامل تور و رزرو
- **فروشگاه تجهیزات** — خرید و اجاره روزانه، فیلترهای پیشرفته، مقایسه محصولات
- **پنل مسافر** — رزروها، سفارش‌ها، علاقه‌مندی‌ها، نشان‌ها و امتیاز XP
- **پنل لیدر تور** — ساخت و مدیریت تور، رزروها، پیام‌ها، آمار رقابتی، نشان‌های افتخار و سطح‌بندی
- **پنل فروشنده** — مدیریت محصولات با فیلتر، سفارش‌ها، نظرات، نمودار روند فروش
- **پنل مدیر کل** — آمار کامل پلتفرم، نمودار درآمد ۱۲ ماهه، مدیریت تورها/تجهیزات/لیدرها/فروشندگان/کاربران/تراکنش‌ها
- مجله سفر، مقاصد، برنامه‌ریز هوشمند، اتاق سفر زنده، مرکز ایمنی و …

## 🆕 تغییرات این نسخه (فیکس‌های ناوبری و فیلترها)

- **رفع باگ دسترسی به پنل‌ها (مهم)** — اگر با یک نقش وارد شده بودید و در
  گیت پنل‌ها (مدیر/فروشنده/لیدر) روی دکمه ورود کلیک می‌کردید، مودال ورود
  بلافاصله بسته می‌شد و پنل باز نمی‌شد. حالا مودال باز می‌ماند و با
  «ورود سریع (دمو)» می‌توانید نقش را عوض کنید و پنل را ببینید.
- **منوی پروفایل نوبار** — بازسازی کامل: آیتم «پروفایل من» برگشت (می‌رود به
  تب ویرایش پروفایل داشبورد)، هدر منو با آواتار + نام + نقش، تراز مرکزی
  منو زیر آیکون، آیکون‌های اختصاصی برای هر آیتم.
- **سایدبار فیلتر صفحه تجهیزات** — دقیقاً مثل سایدبار تورها: پنل استاتیک
  در جای طبیعی خودش، بدون اسکرول داخلی و بدون چسبندگی؛ لیست برندها کامل
  باز شده و دکمه «حذف همه فیلترها» همیشه در دید است.
- **سایدبار فیلتر محصولات پنل فروشنده** — همان سایدبار صفحه تجهیزات
  (جستجو + دسته‌بندی + وضعیت + نوع دسترسی + مرتب‌سازی + حد قیمت +
  برندها) برای تب «محصولات»؛ در موبایل به شیت فیلتر تبدیل می‌شود.
- **دپ‌لینک تب داشبورد** — `/dashboard?tab=settings` مستقیماً تب
  تنظیمات/پروفایل را باز می‌کند؛ جابه‌جایی بین تب‌ها URL را به‌روز نگه
  می‌دارد (رفرش همان تب را نشان می‌دهد).

## ✨ اجرای لوکال (بدون نیاز به هیچ سرویس خارجی)

پروژه یک اپلیکیشن **Next.js 16 (App Router)** است که داده‌های نمایشی را در
localStorage مرورگر نگه می‌دارد — پس بدون دیتابیس خارجی، بدون کلید API و
کاملاً آفلاین کار می‌کند.

### پیش‌نیازها

فقط یکی از این دو:

| ابزار | نسخه پیشنهادی | دانلود |
|---|---|---|
| **Bun** (پیشنهادی — سریع‌تر) | 1.1+ | https://bun.sh |
| **Node.js** | 20+ | https://nodejs.org |

### مراحل اجرا

```bash
# ۱) نصب وابستگی‌ها
bun install        # یا: npm install

# ۲) فایل محیطی (اختیاری — .env همراه پروژه هست؛ در صورت نبود، همین را بسازید)
cp .env.example .env

# ۳) اجرا در حالت توسعه
bun run dev        # یا: npm run dev

# ۴) باز کردن در مرورگر
# http://localhost:3000
```

همین! سایت باید مثل نسخه‌ی منتشرشده، روان و بدون باگ بالا بیاید.

### اجرا در حالت Production (اختیاری)

```bash
bun run build      # یا: npm run build
bun run start      # یا: npm run start  (روی پورت 3000)
```

> نکته: `bun run dev` لاگ سرور را در `dev.log` هم می‌نویسد.

### ورود به پنل‌ها (حالت نمایشی)

از دکمه «ورود | ثبت‌نام» بالای سایت استفاده کنید و نقش دلخواه را انتخاب کنید:

| نقش | مسیر پنل |
|---|---|
| مسافر | `/dashboard` (داشبورد من — تب پروفایل: `/dashboard?tab=settings`) |
| لیدر تور | `/leader/dashboard` (پنل لیدر) |
| فروشنده | `/seller/dashboard` (پنل فروشنده) |
| مدیر کل | `/admin/dashboard` (پنل مدیریت) |

برای دیدن پروفایل عمومی لیدر به‌عنوان خود لیدر (با دکمه «ویرایش پروفایل من»)،
ابتدا با نقش لیدر وارد شوید.

### عیب‌یابی

- **پورت ۳۰۰۰ اشغال است؟** دستور `npx kill-port 3000` یا پورت را در
  `package.json` (اسکریپت dev) تغییر دهید.
- **صفحه خالی بود؟** یک‌بار رفرش سخت بزنید (`Ctrl+Shift+R`)؛ سرویس‌ورکر
  آفلاین ممکن است نسخه قدیمی را کش کرده باشد — از DevTools › Application ›
  Service Workers هم می‌توانید Unregister کنید.
- **داده‌های نمایشی به‌هم ریخت؟** از پنل مدیر › تنظیمات › «پاک کردن همه
  داده‌های نمایشی» استفاده کنید (localStorage پاک می‌شود).

## 🗂 ساختار پوشه‌ها (خلاصه)

```
src/
├─ app/                  # روت‌های App Router
├─ components/
│  ├─ views/             # ویوهای اصلی صفحه (تورها، تجهیزات، پنل‌ها، …)
│  ├─ layout/            # نوبار، فوتر، دراورها، مرکز اعلان‌ها
│  ├─ ui/                # کامپوننت‌های shadcn/ui
│  └─ …
├─ lib/                  # هلپرها (فرمت اعداد/تاریخ، ترندها، سطح‌بندی لیدر، …)
├─ store/                # state های zustand (persist در localStorage)
├─ mocks/                # داده‌های نمایشی (تور، تجهیزات، لیدرها، …)
└─ hooks/
db/custom.db             # SQLite محلی (الان استفاده‌ی فعال ندارد)
prisma/                  # اسکیمای Prisma
```
